# Gold Price Calculator — Installable PWA

1. Upload this folder to any HTTPS static host (for example GitHub Pages).
2. Open the resulting HTTPS URL in Chrome on Android.
3. Chrome will offer "Install app" / "Add to Home screen".
4. Install it and launch it from the Gold Calculator icon.

The calculator supports 24K/22K/18K, weight, making charges, GST, automatic market-rate refresh and manual rate editing.

Note: browser security and HTTPS requirements mean a local `file://` HTML file cannot be installed as a PWA directly.
